# Prijsscanner

Scan een barcode en zie waar het goedkoper is. Alles draait in de browser.
Bronnen: Open Food Facts, Open Prices, Checkjebon en dagelijkse productbestanden van webshops via partnerprogramma's.
Links naar webshops kunnen partnerlinks zijn: koop je via zo'n link iets, dan krijgt de app een vergoeding van de winkel. Je betaalt niets extra.

Privacy: geen account en geen tracking; lijstjes, voorkeuren en allergieën blijven op je telefoon. Zie "Over deze app en privacy" onderaan in de app.
